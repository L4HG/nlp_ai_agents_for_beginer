# Картинки и мемы к трём колодам

Подбор визуала — смешного и объясняющего — к слайдам всех трёх презентаций.
Задача этой папки: чтобы можно было за один вечер отсмотреть кандидатов,
выкинуть лишнее и вставить оставшееся в колоды.

## Что здесь лежит

| Файл | Что |
|---|---|
| `catalog-01-nlp-osnovy.md` | Слайд → картинка для части 1, с подписями и ссылками |
| `catalog-02-llm-i-agenty.md` | То же для части 2 |
| `catalog-03-workshop.md` | То же для части 3 |
| `fetch.sh` | Скачивает всё общедоступное в `downloaded/` (запускать на своей машине) |
| `downloaded/` | Появится после запуска скрипта; в git не попадает |

## Как пользоваться

```bash
cd assets/memes
./fetch.sh          # скачает ~25 файлов: Wikimedia Commons, xkcd, шаблоны imgflip
```

Скрипт в конце печатает, что не скачалось (имена файлов на Commons иногда
меняются). Для каждой позиции в каталоге есть поисковый запрос — если ссылка
умерла, картинка находится за 30 секунд.

Сборка курса шла из окружения без доступа к файловым хостам, поэтому картинки
не скачаны заранее — скрипт делает это на вашей машине за один запуск.

## Три типа позиций в каталогах

1. **Скачивается скриптом** — свободная лицензия (public domain, CC) или
   открытый шаблон. Помечено `fetch.sh → путь`.
2. **Шаблон + ваши подписи** — классический мем-шаблон (Дрейк, «неверный
   парень» и т.п.): скрипт скачивает пустой шаблон, подписи из каталога
   накладываются в любом редакторе или на imgflip.com/memegenerator.
3. **Только описание** — кадры из фильмов и скриншоты чужих продуктов.
   Их не скачать легально «в лоб», но по поисковому запросу из каталога
   они находятся мгновенно; решение об использовании — за вами
   (для внутреннего обучения риск обычно принимают).

## Как вставить картинку в слайд

`--allow-local-files` в Makefile уже включён, поэтому достаточно:

```markdown
![w:560](../assets/memes/downloaded/01/2-4-eliza.png)
```

Готовый паттерн «слайд-мем» (картинка + одна строка вывода):

```markdown
---

<!-- @ 2.4a eliza мем -->

## Секретарь просила выйти из комнаты

![w:640](../assets/memes/downloaded/01/2-4-eliza.png)

<p class="muted">200 строк кода — и человек уже доверяет машине секреты.</p>
```

## Сколько мемов оставлять

Проверенная пропорция для управленческой аудитории — **один мем на 5–7
содержательных слайдов**, в местах проседания внимания: середина каждого часа
и переходы между блоками. Каталоги ниже сознательно избыточны (кандидатов
в 3–4 раза больше, чем нужно) — большую часть предполагается выкинуть.

## Лицензии — коротко

- **Wikimedia Commons** (Тьюринг, ELIZA, фото) — public domain или CC,
  можно свободно; для CC BY указать автора мелким шрифтом в углу слайда.
- **xkcd** — CC BY-NC 2.5: некоммерческое использование с подписью «xkcd.com»
  разрешено автором явно. Для внутреннего обучения — нормально.
  Есть русские переводы на xkcd.ru — номера комиксов совпадают.
- **Кадры из фильмов / мем-шаблоны** — формально копирайт, фактически
  общепринятое мем-использование. В раздатки и публичные материалы лучше
  не класть, на экране в зале — обычная практика.
