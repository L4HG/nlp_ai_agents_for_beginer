# Каталог картинок · Часть 3 «Воркшоп»

В воркшопе слайды в основном инструктивные — здесь мемы работают как разрядка
между шагами и как «доска» на время самостоятельной работы. Рекомендуемый
максимум — 4–6 картинок: на воркшопе внимание должно быть в ноутбуках,
а не на экране. ⭐ — лучшие кандидаты.

Отдельно: в заметках колоды уже запланированы **скриншоты с репетиции
установки** (@ 1.1a, шаги Hermes). Это важнее любых мемов — см. чек-лист
в README репозитория.
