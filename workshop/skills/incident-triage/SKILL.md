# Триаж инцидента

## Когда применять

- Применять: пришло описание проблемы или сбоя, надо определить приоритет и что делать первым.
- Не применять: просят свести отчёты за смену — для этого есть скилл `smena-svodka`.

## Что нужно на входе

- Описание инцидента в свободной форме.
- Время обнаружения, если оно известно.

Ничего из недостающего не додумывай — выпиши в раздел «Чего не хватает».

## Что делать

1. Определи категорию инцидента.
2. Оцени влияние и срочность, затем найди приоритет по матрице ниже.
3. По приоритету определи, кого оповестить.
4. Сформулируй первые три действия — конкретных, выполнимых сейчас.
5. Перечисли, какие данные нужны, чтобы уточнить оценку.

### Категории

`Доступность` · `Производительность` · `Данные` · `Безопасность` · `Внешний поставщик` · `Прочее`

### Матрица приоритета

| Влияние \ Срочность | Низкая | Средняя | Высокая |
|---|---|---|---|
| **Единичный пользователь** | P4 | P4 | P3 |
| **Подразделение** | P3 | P3 | P2 |
| **Вся компания или клиенты** | P2 | P1 | P1 |

### Кого оповещать

- **P1** — руководитель операционного центра немедленно, дежурный менеджер, владелец сервиса.
- **P2** — дежурный менеджер, владелец сервиса.
- **P3** — ответственная команда.
- **P4** — очередь на разбор, без отдельного оповещения.

> Матрица и список оповещения — это ваши правила. Меняйте их прямо в этом файле:
> так подстраиваются регламенты под конкретное подразделение.

## Формат ответа

```
## Категория
<одна из списка>

## Приоритет
<P1–P4> — влияние: <...>, срочность: <...>

## Кого оповестить
<роли, по одной в строке>

## Первые три действия
1. <...>
2. <...>
3. <...>

## Чего не хватает
<пункты, либо «данных достаточно»>
```

## Чего не делать

- Не повышай и не понижай приоритет «по ощущению» — только по матрице выше.
- Не выдумывай факты о системах, которых нет в описании.
- Не предлагай действий, требующих данных, которых у тебя нет.
- Не пиши «необходимо провести анализ» — это не действие. Пиши, что именно посмотреть и где.
- Если из описания нельзя определить влияние — ставь пометку «влияние не определено» и не угадывай.
