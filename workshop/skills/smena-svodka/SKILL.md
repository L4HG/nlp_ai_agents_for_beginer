# Сводка по отчётам смены

## Когда применять

- Применять: просят свести отчёты смены, подготовить передачу смены, собрать итоги суток.
- Не применять: просят разобрать один конкретный инцидент — для этого есть скилл `incident-triage`.

## Что нужно на входе

- Тексты отчётов за смену (один или несколько).
- Период, за который делается сводка.

Если период не указан — возьми его из самих отчётов и напиши, какой взял.
Если отчётов меньше двух, а просят «свести» — спроси, все ли отчёты приложены.

## Что делать

1. Собери все события в единый список и упорядочь по времени.
2. Раздели события на закрытые и оставшиеся открытыми.
3. Для каждого открытого события найди ответственного. Не нашёл — так и напиши.
4. Выпиши отклонения от нормативов вместе с числами из отчётов.
5. Отдельно собери то, что передаётся следующей смене.
6. Перечисли, каких данных не хватило.

## Формат ответа

```
## Период
<даты и время>

## Что произошло
<события по времени, по одной строке на событие>

## Осталось открытым
<событие — ответственный — что требуется>

## Отклонения
<показатель — факт — норматив>

## Передаётся следующей смене
<пункты>

## Не хватило данных
<пункты, либо «всё есть»>
```

Не длиннее одной страницы. Если событий слишком много — группируй однотипные
и указывай количество, а не перечисляй каждое.

## Чего не делать

- Не выводи ни одного числа, которого нет во входных данных. Нет числа — пиши «нет данных».
- Не пиши «в целом смена прошла штатно» и другие оценки. Только факты из отчётов.
- Не додумывай ответственных по смыслу — только если фамилия названа в отчёте.
- Не объединяй разные инциденты в один, даже если они похожи.
- Не добавляй рекомендаций, если их не просили.
