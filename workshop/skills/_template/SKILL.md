## Формат ответа

Опишите структуру жёстко, по пунктам. Это единственный способ получать
одинаковый результат каждый раз.

```
## Раздел 1
<что здесь>

## Раздел 2
<что здесь>
```

Ограничение объёма: <не длиннее одной страницы / не более N строк>.

## Чего не делать

Самый важный раздел. Сюда идёт всё, что вас раздражает в чужих отчётах.

- Не выводи ни одного числа, которого нет во входных данных. Нет данных — пиши «нет данных».
- Не заменяй отсутствующий факт формулировкой общего характера.
- Не добавляй разделы, которых нет в формате выше.
- Не пиши вступлений и заключений — только по делу.
