# Дайджест по показателям

## Когда применять

- Применять: есть таблица или выгрузка метрик, нужен короткий разбор к планёрке.
- Не применять: просят подробный аналитический отчёт с выводами и прогнозом.

## Что нужно на входе

- Значения показателей за текущий период.
- Значения за предыдущий период или нормативы — иначе сравнивать не с чем.

Если нет базы для сравнения — скажи об этом сразу и не считай динамику.

## Что делать

1. Посчитай изменение по каждому показателю относительно предыдущего периода.
2. Выбери три самых значимых роста и три самых значимых падения.
3. Отдельно выпиши всё, что вышло за норматив, — независимо от величины изменения.
4. Сформулируй **одну** гипотезу, что могло повлиять. Обозначь её как гипотезу.
5. Сформулируй **один** вопрос, который стоит задать на планёрке.

## Формат ответа

Ровно пять строк, без заголовков и вступлений:

```
Выросло: <показатель> <было → стало> (<±%>); <показатель> ...
Упало: <показатель> <было → стало> (<±%>); ...
Пробило порог: <показатель> <значение> при нормативе <значение>
Гипотеза: <одно предложение, начиная со слова «возможно»>
Вопрос на планёрку: <одно предложение>
```

Если по какой-то строке сказать нечего — пиши «нет».

## Чего не делать

- Ни одного утверждения без числа рядом. «Заметно выросло» — так писать нельзя.
- Не выводи ни одного числа, которого нет во входных данных, кроме процентов изменения,
  которые считаются из них же.
- Не выдавай гипотезу за установленную причину. Только формулировка «возможно».
- Не больше одной гипотезы и одного вопроса, даже если напрашивается больше.
- Не добавляй рекомендаций и планов действий — это не задача дайджеста.
